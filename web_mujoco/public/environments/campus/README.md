# Campus building asset

- Source: https://github.com/achrefelouafi/ProceduralBuildingsThreeJS
- Pinned source commit: `6c19f1b1f14408353989ad26cda27f1e1ede5e91`
- Original author: mohamedachrefelouafi
- Original model: `blender/CN_ApartmentBuilding.blend`, evaluated through the
  upstream exported geometry graph and module kit in `public/assets/cn/`.
- Code and model license: MIT; the original notice is included in `LICENSE.txt`.
- Embedded texture sets: ambientCG, CC0, as identified by the upstream README:
  PaintedPlaster017, Tiles138, Concrete034, Concrete036, CorrugatedSteel005,
  RoofingTiles012A. https://ambientcg.com/

`chinese-building.glb` is a derived, static LOD1 export with a footprint of
8 × 6 m before balconies / facade details and three storeys. Sidewalks and
street props are generated by this project's shared campus layout instead.
The asset uses Z-up coordinates in metres, matching the MuJoCo renderer.

The importer preserves the original geometry, UVs and vertex attributes,
converts materials to simplified standard glTF PBR, embeds selected textures,
and indexes duplicate vertices. It does not reproduce all procedural Blender
shader effects. `building.json` records the input parameters, measured mesh
bounds, triangle count and content version used by the cache.

Rebuild from the repository's `web_mujoco` directory:

```bash
node scripts/import-campus-building.mjs /path/to/ProceduralBuildingsThreeJS
node scripts/build-campus-scene.mjs
```

The build does not require Blender. Upstream geometry and shading code are
used only during import and are not included in the browser's runtime.
